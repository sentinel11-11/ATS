# ATS — система автоматического обзвона (исходящие кампании)

Проект развивался в две итерации:

- **`README_RU.txt` + `server.py`, `xp_bridge/`, `static/`** — исходный прототип «диспетчер очереди на GSM-модемах» (legacy, не используется новой версией).
- **`app/` (ATS v2)** — переработанная платформа исходящего обзвона под требования заказчика: кампании («карусель»), автодозвон, пул номеров с ротацией Caller ID, согласия/чёрный список, ИИ-агент, перевод на сотрудника (ACD), телефония и CRM за интерфейсами-адаптерами, SQLite, REST API v2, веб-UI, тесты.

## Быстрый старт (v2)

```bash
./run_ats2.sh                      # Linux/macOS (данные в ./data_v2)
# Windows: run_ats2.bat
# ATS_ADMIN_PASSWORD='...' python3 -m app.run --host 0.0.0.0 --port 9124
```

При первом запуске создаются `data_v2/ats.db` и файл `data_v2/initial_credentials.txt` с паролем администратора (роль admin). Операторов добавляет администратор: Настройки → Пользователи и операторы. Пул номеров и база стартуют пустыми — номера и контакты добавляются в интерфейсе. Интерфейс: `http://127.0.0.1:9124`.

Тесты: `python3 -m unittest discover -s tests -v` (57 проверок: ядро, пул, E2E, HTTP API, AMI-протокол, вебхуки UIS, ACD, базы/импорт Excel, hardening). В тестах пул sim-номеров наполняется автоматически (`ATS_DEV_SEED=1`), в продукте — пуст.

  цикл звонка, автодозвон, пул номеров, ИИ-агент, ACD, гарантии доставки в CRM, безопасность,

  синк пула, что уже работает и что нужно от оператора).

  преимущества АТС, сравнение с аналогами, модель монетизации, план пилота.
- `docs/DEPLOY.md` — **установка, запуск и ОБНОВЛЕНИЕ НА СЕРВЕРЕ** (`deploy/update.sh`,
  автооткат, бэкапы, systemd, Nginx/SSE, Windows `deploy/update.ps1`).
- `docs/ADMIN_LOGS.md` — аудит админских действий (`audit_logs`).
- `README_V2.md` — быстрый старт v2, устройство кода, полный список REST-маршрутов, статусы.
- `LIVE_TEST_MEGAFON.md` — чек-лист проверки связки с МегаФон ВАТС на живом стенде.

## Обновление на сервере (одна команда)

```bash
cd /opt/ats && ./deploy/update.sh arena/01a0cdee-ats
#   бэкап БД → ff-only merge → тесты → рестарт → health-check → автооткат, если не поднялся
./deploy/update.sh --rollback      # откат на предыдущую ревизию
```
Подробно: `docs/DEPLOY.md` (в т.ч. Windows-версия `deploy/update.ps1`).
