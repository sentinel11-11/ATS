### Шаг 2 — локальная очистка

```bash
# 2.1. Зеркальный бэкап ВСЕГО (до любых действий)
git clone --mirror https://github.com/sentinel11-11/ATS.git ats-backup-$(date +%F).git

# 2.2. Рабочая копия для переписывания
git clone --mirror https://github.com/sentinel11-11/ATS.git ats-clean.git
cd ats-clean.git

# 2.3. filter-repo (поставить: pip install git-filter-repo)
git filter-repo --invert-paths \
    --path data_v2/ats.db \
    --path data_v2/initial_credentials.txt \
    --path deploy/asterisk/sip-multicom.conf \
    --path deploy/asterisk/install-multicom-trunk.sh \
    --path docs/MULTICOM_INTEGRATION.md \
    --path docs/MULTICOM_SETUP_STEPS.md \
    --path docs/MULTICOM_SIP_CONNECT.md

# 2.4. Проверка: сканер должен дать 0 по ВСЕМ refs
git log --all --oneline -- data_v2/ | wc -l          # 0
python3 tools/secret_scan.py --history               # 0 попаданий
```

Примечание: удаление `deploy/asterisk/*` и `docs/MULTICOM_*` целиком —
опция «максимальной чистоты»; их актуальные версии уже обезличены
(плейсхолдеры), поэтому допустимо вместо `--invert-paths` точечно заменить
содержимое (replace-text) — тогда файлы сохранятся в истории, но без
литералов. Решение за владельцем; default — точечная замена:

```bash
git filter-repo --replace-text <(printf '%s\n' \
  '95.1XX.XX.XX==>REDACTED' '0008==>REDACTED' \
  '9863XXXXXXXX==>REDACTED' '9362XXXXXXXX==>REDACTED' '9690XXXXXXXX==>REDACTED')
# точные значения — из вывода одноразового диагностического прогона
# secret_scan --history --weak --max-hits 1000 на зеркале (значения
# сканер не печатает — выписать вручную из diff старых коммитов)
```

### Шаг 3 — публикация переписанной истории

```bash
cd ats-clean.git
git push --force --mirror origin
```

ВНИМАНИЕ: force-push в этой среде агента заблокирован правилами — шаг
выполняет владелец с локальной машины (или явно поручает агенту в сессии
с отдельным одобрением).
