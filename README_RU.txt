ATS Dispatcher — обзвон 

Запуск для проверки без телефонного оборудования:
1. Запустите run_web_ats.bat.
2. Запустите start_xp_bridge.bat.
3. В браузере откроется интерфейс.
4. Логин: admin
5. Пароль: admin1234
6. По умолчанию включён тестовый режим. Добавьте контакты, отметьте разрешение на обзвон, выберите шаблон и отправьте контакты в очередь.

Подключение линий:
1. Установите драйвер модема/телефонного интерфейса, чтобы каждая линия имела свой COM-порт.
2. В разделе «6 линий» для нужной линии выберите «COM / модем».
3. Укажите COM-порт и скорость.
4. Для стандартного голосового GSM-модема используются ATD + номер + ; и ATH. При необходимости измените команды под оборудование.
5. В общих настройках отключите тестовый режим.
6. Запустите ATS_6Line_Bridge.

Озвучка:
Шаблоны редактируются в интерфейсе. Поддерживаются {name}, {phone}, {group}, {note}. Предварительное прослушивание выполняется браузером. При реальном вызове мост использует Windows SAPI либо заданную для линии внешнюю команду подачи аудио. Реальная передача звука в телефонный тракт зависит от используемого модема/АТС/аудиоинтерфейса.

База обзвона:
CSV: Имя;Телефон;Группа;Примечание;1
Последнее поле 1 означает наличие разрешения на автоматический обзвон.

Сборка EXE:
Запустите build_exe_win10.bat. Готовые файлы появятся в папке dist.
