# ATS v2 — что сделано в проекте (история изменений)

**ATS v2** — платформа исходящего обзвона (call-центр): кампании с расписанием и
автодозвоном, пул номеров Caller ID с защитой от антиспама, ИИ-агент для
квалификации звонков, перевод на оператора (ACD), журнал и отчёты, записи
разговоров, интеграции с телефонией (UIS / Asterisk AMI / симулятор) и CRM
(CSV / Bitrix24). Всё в одном процессе, без внешних зависимостей (SQLite,
стандартная библиотека Python), одиночный HTML-файл интерфейса.

Ветка разработки: `arena/01a072c1-ats` (Pull Request №1 в GitHub).
Ниже — изменения по коммитам, от старого ядра к текущему интерфейсу.

---

## 1. Платформа исходящего обзвона — ядро, API, UI, телефония/CRM, тесты
**Коммит `2799c3d`**

- **Движок обзвона** (`app/engine.py`): очередь кампаний, окно звонков и дни
  недели, попытки дозвона и базовые интервалы повторов, суточные лимиты и
  «остывание» номеров, автокарантин номера при жалобах, ACD-очередь на
  оператора, «зависшие» звонки (watchdog).
- **ИИ-агент**: квалификация абонентов по сценарию (вопросы/ответы 1/2),
  перевод «квалифицированных» на оператора, отказ при отсутствии согласия,
  чёрный список «не звонить».
- **Телефония** (`app/telephony.py`): симулятор без оборудования + UIS
  (МегаФон «Ювис» Call API). **CRM**: выгрузка CSV + вебхук Bitrix24.
- **REST API v2** (`app/api.py`): авторизация с токеном, роли admin/operator,
  контакты/номера/кампании/шаблоны/операторы/журнал/чёрный список/настройки,
  события в реальном времени (SSE), вебхук UIS.
- **UI v2** (`app/ui/index.html`): одиночная страница со всеми разделами.
- Перенос legacy-данных (контакты/шаблоны старой версии), тесты.

## 2. AMI-клиент Asterisk, UIS-вебхук, ACD-timeout, документация
**Коммит `dfa623a`**

- Клиент Asterisk AMI (`app/asterisk.py`) — реальный SIP-провайдер для
  клиентской АТС (originate/состояния/завершение), «проверка соединения».
- UIS: приём webhook-событий от Call API и перевод их в события движка.
- ACD: таймаут ожидания оператора → результат `no_operator` + задача на
  перезвон.
- Настройки `uis/ami/llm/bitrix24` в конфигурации, единый REST под RAW-конфиг.
- Документация: `README_V2.md`, `ПЛАН_ДОРАБОТКИ_ATS.md`, `ДОРОЖНАЯ_КАРТА_ATS.md`,
  скрипты запуска `run_ats2.bat/.sh`, расширенные тесты.

## 3. Отчёты, защита входа от перебора, экспорт журнала, UX
**Коммит `003f68f`**

- **Отчёты**: за сегодня, по кампаниям, по Caller ID, динамика 7 дней;
  карточки-метрики в UI.
- **Защита от перебора пароля**: задержки/блокировка после неудачных входов
  (429 + `retry_after_sec`).
- **Экспорт журнала** звонков в CSV; фильтр журнала по результату.
- Интерфейс: статусы звонков бейджами, кнопки действий в таблицах, авто-бэкап
  базы при старте сервера.

## 4. Записи разговоров, умный автодозвон, демо-данные, авто-бэкап БД
**Коммит `9e55aca`**

- **Записи разговоров**: загрузка файла по звонку (админ), прослушивание из
  UI, папка `data_v2/recordings/`.
- **Умный автодозвон**: `retry_map` кампании — индивидуальные паузы повтора по
  причинам (занято → 5 мин, нет ответа → 20 мин и т.п.), редактор в форме
  кампании.
- **Демо-данные** одной кнопкой: контакты + «Демо-кампания (ИИ-агент)».
- **Авто-бэкап БД** при каждом старте: `data_v2/backups/ats-ГГГГММДД-ЧЧММСС.db`,
  хранение последних 12 копий.
- Загрузка записи разговора и демо-режим покрыты тестами.

## 5. Ровная адаптивная вёрстка без «дёрганий»
**Коммит `ead9151`**

- Единые отступы/типографика: сетки форм (`.formgrid`), компактные кнопки,
  липкий сайдбар, адаптив под узкие экраны.
- «Настройки»: двухколоночная форма, расписание звонков со временем и чипами
  дней недели; панели RAW-конфига и смены пароля — только у администратора.
- **Анти-jank**: дебаунс обновлений по SSE, локальный фильтр контактов без
  лишних запросов, защита от гонок при переключении вкладок, плавные модалки.

## 6. Современный интерфейс: палитра, тосты, живые панели, диаграммы, роли
**Коммит `0dccfdb`**

- **Дизайн**: «стеклянные» панели с блюром, градиенты, иконки, аватары,
  аккуратные тосты вместо `alert/confirm`.
- **Экран входа** на весь экран; интерфейс **подстраивается под роль**:
  оператор видит приём звонков/статусы/базу, админ — всё управление
  (недоступные кнопки скрыты).
- **Быстрый доступ**: `Ctrl+K` — палитра переходов (разделы, кампании,
  контакты), `F5` — обновление раздела, индикатор live-подключения.
- **Обзор**: метрики с иконками, пул номеров с прогресс-барами лимита дня,
  лента последних звонков.
- **Кампании**: детальная карточка с метриками, переключатель
  «Контакты / Звонки», запуск/пауза/остановка, загрузка записей.
- **ACD**: карточки очереди и операторов; при приёме — панель «Активный
  разговор» с кнопкой завершения; статусы «Свободен/Перерыв» в шапке.
- **Отчёты**: диаграммы результатов/кампаний/номеров + 7-дневный тренд.
- **Журнал**: человеческие названия результатов, длительность разговора,
  кнопка «Показать ещё».
- **Контакты**: выбор строк кликом + панель массовых действий
  («Добавить в кампанию», «Удалить»).
- **Исправлено**: `/acd/accept` возвращает `operator_id`, поэтому после
  «Завершить разговор» оператор корректно освобождается (раньше «залипал»).

## Запуск

Windows (PowerShell, из папки проекта, в виртуальном окружении):

```powershell
cd "C:\Users\ilaci\OneDrive\Рабочий стол\ATS"
python -m app.run
```

или двойным кликом/командой: `.\run_ats2.bat`

После старта откройте **http://localhost:9124**

- Порт и хост по умолчанию: `0.0.0.0:9124` (доступен в локальной сети).
- Провайдер/порт можно менять: `python -m app.run --port 9000 --provider uis`.
- **Первый запуск**: создаётся `data_v2/` с базой и файлом учётных данных
  `data_v2/initial_credentials.txt` (логин `admin` + сгенерированный пароль,
  печатается и в консоль; оператор-демо: `operator / operator1234`).
- Управление операционной конфигурацией (UIS/Asterisk/LLM/Bitrix24) — в
  разделе «Настройки → Провайдеры и интеграции» (только админ).
- Авто-бэкапы БД: `data_v2/backups/`.
